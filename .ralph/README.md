# Ralph Queue

`.ralph/prd.json` is the historical PRD and user-story queue for the current KishOS feature pass. As of 2026-06-04, all listed stories are passing.

Run the verifier from the repo root:

```bash
.ralph/verify.sh
```

For current roadmap status, use `docs/ROADMAP.md`. Treat this folder as queue history plus verification scripts, not as the live roadmap.
